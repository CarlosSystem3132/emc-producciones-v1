# Panel del administrador

## Objetivo

El panel del administrador debe permitir planificar, administrar, supervisar
y controlar toda la operación comercial de EMC Producciones.

## Permisos exclusivos

El administrador es el único usuario autorizado para:

- Crear ejecutivos de ventas.
- Editar ejecutivos de ventas.
- Bloquear ejecutivos de ventas.
- Desactivar ejecutivos de ventas.
- Eliminar ejecutivos de ventas.
- Cambiar roles.
- Restablecer contraseñas.
- Asignar rubros o zonas.
- Reasignar empresas.
- Aprobar campañas masivas.
- Configurar precios y reglas comerciales.

## Secciones principales

### Dashboard

Debe mostrar:

- Porcentaje de ocupación global.
- Stands disponibles.
- Stands bloqueados.
- Stands reservados.
- Stands vendidos.
- Canchas de maquinaria disponibles y vendidas.
- Ventas totales.
- Ventas proyectadas.
- Empresas contactadas.
- Empresas interesadas.
- Empresas en negociación.
- Embudo comercial.
- Desempeño por ejecutivo.
- Avance semanal.
- Alertas críticas.

### Gestión de ejecutivos

El administrador debe poder:

- Crear ejecutivos.
- Editar ejecutivos.
- Ver ejecutivos.
- Bloquear ejecutivos.
- Desactivar ejecutivos.
- Eliminar ejecutivos.
- Cambiar roles.
- Restablecer contraseñas.
- Asignar rubros o zonas.
- Ver carga de trabajo.
- Ver desempeño comercial.
- Ver empresas asignadas.
- Reasignar empresas.

### Crear ejecutivo

El administrador debe poder registrar:

- Nombre completo.
- Correo de acceso.
- Contraseña inicial.
- Teléfono.
- WhatsApp.
- Correo de contacto.
- Cargo.
- Experiencia.
- Especialidad.
- Foto de perfil.
- Estado.

### Editar ejecutivo

El administrador puede editar:

- Datos personales.
- Datos de contacto.
- Cargo.
- Experiencia.
- Especialidad.
- Estado.
- Rol.
- Asignaciones.

### Bloquear ejecutivo

El bloqueo debe impedir el acceso al panel, pero conservar:

- Empresas asignadas.
- Leads.
- Reservas.
- Ventas.
- Comunicaciones.
- Historial comercial.

### Eliminar ejecutivo

Antes de eliminar, el sistema debe verificar si el ejecutivo tiene:

- Empresas asignadas.
- Leads activos.
- Reservas activas.
- Ventas registradas.
- Comunicaciones asociadas.

Si existen registros, el sistema debe sugerir reasignación o desactivación
en lugar de eliminación física.

### Empresas

Debe permitir:

- Crear, editar y eliminar empresas.
- Buscar y filtrar empresas.
- Importar desde Excel o CSV.
- Exportar a Excel o CSV.
- Asignar ejecutivos.
- Cambiar estados.
- Ver historial completo.
- Detectar duplicados.
- Administrar contactos.

### Leads

Debe permitir:

- Ver embudo comercial.
- Filtrar por estado, rubro, prioridad y ejecutivo.
- Asignar ejecutivos.
- Cambiar estados.
- Registrar actividades.
- Programar seguimientos.
- Ver historial.

### Stands

Debe permitir:

- Crear, editar y eliminar stands.
- Administrar zonas.
- Definir dimensiones y precios.
- Administrar disponibilidad.
- Ver plano visual.
- Asignar ejecutivos.
- Ver historial de reservas.
- Configurar reglas de bloqueo.

### Paquetes

Debe permitir:

- Crear paquetes.
- Editar paquetes.
- Definir beneficios.
- Definir precios.
- Definir condiciones.
- Asociar paquetes a stands.
- Ver desempeño de paquetes.

### Campañas

Debe permitir:

- Crear segmentos.
- Seleccionar plantillas.
- Programar envíos.
- Definir límites diarios.
- Aprobar campañas.
- Ver resultados.
- Detectar errores y rebotes.

### Chat

Debe permitir:

- Ver conversaciones activas.
- Ver historial por empresa.
- Transferir conversaciones.
- Editar respuestas frecuentes.
- Revisar casos escalados.
- Monitorear calidad.

### Reportes

Debe permitir:

- Reporte de ocupación.
- Reporte de ventas.
- Reporte por ejecutivo.
- Reporte por rubro.
- Reporte por campaña.
- Reporte de reservas.
- Reporte de ingresos.
- Exportación a Excel, CSV o PDF.

### Configuración

Debe permitir:

- Administrar usuarios.
- Administrar roles.
- Configurar precios.
- Configurar reglas.
- Configurar plantillas.
- Configurar límites de envío.
- Configurar duración del bloqueo.
- Configurar integraciones.
